## ☕ Projeto em destaque — CoffeStar

Análise de vendas e rentabilidade de uma rede fictícia de cafeterias.

O projeto reúne:

- Visão geral de receita, lucro operacional e margem.
- Evolução mensal com histórico fictício e projeção.
- Rankings de lojas e vendedores.
- Filtros interativos e indicadores personalizados.
- Dicionário de dados com definições e regras de cálculo.
